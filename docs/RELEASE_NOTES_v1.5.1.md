# Heist Ledger v1.5.1 - Simpler Downloads

Download **HeistLedger-Setup.exe** below. This is the only file needed to install Heist Ledger on Windows x64. GitHub's Source code archives are for developers, not installation.

- The main release now offers one clearly named installer instead of technical update packages.
- In-app updates use a separate public update repository.
- Existing updater-enabled installations can upgrade through Settings > App Updates using a compatibility feed retained on the older v1.5.0 release.
- Your local earnings, settings, capture, OCR, and confirmation workflow are unchanged.

The installer is not code-signed, so Windows may still show an unrecognized-app warning.
