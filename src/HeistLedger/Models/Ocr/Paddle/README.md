# PaddleOCR model

- Model: `PaddlePaddle/PP-OCRv5_mobile_rec_onnx`
- Source: https://huggingface.co/PaddlePaddle/PP-OCRv5_mobile_rec_onnx
- Publisher: PaddlePaddle / PaddleOCR
- License: Apache License 2.0
- Runtime: local CPU inference through Microsoft ONNX Runtime

`character_dictionary.txt` is extracted from the official model's
`inference.yml` character dictionary. The application does not require Python,
PaddlePaddle, a network connection, or any cloud OCR service at runtime.
